# Countdown webfonts

The plugin serves unmodified fonts from its own directory. WOFF2 files are Google Fonts web builds and retain their upstream character subsets. Each upstream repository below contains the corresponding source. The font licenses apply to their respective standalone assets.

- [Inter](https://github.com/google/fonts/tree/main/ofl/inter) — license included in `assets/fonts/inter/OFL.txt`.
- [Poppins](https://github.com/google/fonts/tree/main/ofl/poppins) — license included in `assets/fonts/poppins/OFL.txt`.
- [Montserrat](https://github.com/google/fonts/tree/main/ofl/montserrat) — license included in `assets/fonts/montserrat/OFL.txt`.
- [Lato](https://github.com/google/fonts/tree/main/ofl/lato) — license included in `assets/fonts/lato/OFL.txt`.
- [Fredoka](https://github.com/google/fonts/tree/main/ofl/fredoka) — license included in `assets/fonts/fredoka/OFL.txt`.
- [Orbitron](https://github.com/google/fonts/tree/main/ofl/orbitron) — license included in `assets/fonts/orbitron/OFL.txt`.
- [Mountains of Christmas](https://github.com/google/fonts/tree/main/apache/mountainsofchristmas) — license included in `assets/fonts/mountainsofchristmas/LICENSE.txt`.
- [Snowburst One](https://github.com/google/fonts/tree/main/ofl/snowburstone) — license included in `assets/fonts/snowburstone/OFL.txt`.
- [Creepster](https://github.com/google/fonts/tree/main/ofl/creepster) — license included in `assets/fonts/creepster/OFL.txt`.
- [Nosifer](https://github.com/google/fonts/tree/main/ofl/nosifer) — license included in `assets/fonts/nosifer/OFL.txt`.
- [Almonte Snow](https://typodermicfonts.com/public-domain/) by Ray Larabie / Typodermic Fonts — CC0 1.0, notice in `assets/fonts/almonte-snow/LICENSE.txt`.

## Custom font uploads

Uploading custom fonts was explored in the 1.0.0-rc.2 release candidate but is **not available in 1.0.0-rc.3**. Existing Media Library attachments created during testing are not deleted by upgrading. Only the bundled fonts listed above may be selected in this release.
